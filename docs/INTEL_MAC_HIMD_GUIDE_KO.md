# Intel Mac용 Web MiniDisc Pro v12 사용 설명서

## 지원 범위

- Intel Mac 전용 `x86_64` 빌드
- Sony MZ-NH1: Intel macOS Sonoma와 Tahoe에서 실기 테스트
- Sony MZ-RH10: Intel macOS Tahoe에서 실기 테스트
- NetMD, Hi-MD, 1GB Hi-MD, PCM 전송 지원
- 목록에 있는 다른 Sony Hi-MD 기기는 호환 펌웨어라면 동작할 가능성이 있지만 미검증

Apple Silicon Mac은 현재 지원하지 않습니다. 이 앱은 Apple Developer ID 공증을 받지
않은 개인용 오픈소스 빌드입니다.

## 설치

1. GitHub Releases에서 `WMDP Intel Hi-MD RAM Patch v12.dmg`를 받습니다.
2. DMG를 열고 `Web MiniDisc Pro.app`을 `Applications` 폴더로 드래그합니다.
3. 처음 실행할 때 Finder의 응용 프로그램에서 앱을 Control-클릭하고 `열기`를 선택합니다.
4. Hi-MD 연결 중 관리자 암호 창이 나타나면 허용합니다.

## 꼭 지킬 사항

- 기기에 배터리 또는 안정적인 외부 전원을 연결합니다.
- 포맷과 녹음 중에는 USB와 전원을 분리하지 않습니다.
- REC 표시가 깜빡이거나 진행률이 99%이면 TOC/FAT/ICV 정보를 마무리하는 중입니다.
  멈춘 것처럼 보여도 점멸이 끝날 때까지 기다립니다.
- RAM 패치는 기기 전원이 완전히 꺼지면 사라집니다. 미디어를 바꿀 때도 배터리나
  외부 전원을 유지하세요.
- 포맷과 초기화는 모든 곡을 지웁니다. 중요한 디스크에는 실행하지 마세요.

## NetMD 사용

1. 일반 MD를 넣고 USB를 연결합니다.
2. 메인 화면에서 `NetMD로 연결`을 누릅니다.
3. 녹음, 제목·그룹 편집, 내려받기 등 NetMD 기능을 사용합니다.

## 기존 Hi-MD 미디어 사용 — 포맷하지 않음

이미 사용 중인 Hi-MD 또는 1GB Hi-MD 미디어를 열 때는 일반 MD를 지울 필요가 없습니다.
처음 한 번 또는 전원이 완전히 꺼져 RAM 패치가 사라졌을 때만 준비합니다.

1. 일반 MD를 넣고 USB를 다시 연결합니다.
2. `NetMD로 연결`이 되는지 확인한 뒤 메인 화면으로 돌아갑니다.
3. `Hi-MD로 연결`을 누르고 `Hi-MD 준비 / 포맷`을 선택합니다.
4. **`RAM 패치만 적용 (미디어 유지)`**를 누릅니다.
5. 완료되면 기기의 배터리 또는 외부 전원을 그대로 유지합니다.
6. 전송 작업이 없는 상태에서 기존 Hi-MD 미디어로 교체합니다.
7. USB 케이블만 한 번 뺐다가 다시 연결한 뒤 `Hi-MD로 연결`을 누릅니다.

`RAM 패치만 적용`은 현재 일반 MD를 지우거나 포맷하지 않습니다. NH1은 USB를 다시
꽂지 않아도 인식할 때가 있지만, RH10을 포함해 미디어 교체 후에는 USB만 재연결하는
방법이 가장 확실합니다.

## 일반 MD 자체를 Hi-MD 형식으로 바꾸기 — 전체 삭제

일반 60/74/80분 MD를 Hi-MD 형식으로 사용하려는 경우에만 실행합니다.

1. 지워도 되는 일반 MD를 넣고 USB를 다시 연결합니다.
2. `NetMD로 연결`이 되는지 확인한 뒤 메인 화면으로 돌아갑니다.
3. `Hi-MD로 연결` → `Hi-MD 준비 / 포맷`을 선택합니다.
4. **`일반 MD를 지우고 Hi-MD로 포맷`**을 선택합니다.
5. 포맷과 마무리가 끝날 때까지 USB와 전원을 유지합니다.
6. 완료 후 `Hi-MD로 연결`을 누릅니다.

이 과정은 디스크의 모든 곡을 삭제합니다. 포맷한 일반 MD는 이후 Hi-MD 미디어처럼
사용할 수 있습니다.

## Hi-MD에서 일반 NetMD 미디어로 교체

서로 다른 NetMD/Hi-MD 미디어를 번갈아 쓸 때는 포맷하지 않습니다.

1. 전송이 끝나고 REC 점멸이 멈춘 것을 확인합니다.
2. 메인 화면으로 돌아간 뒤 일반 NetMD 미디어로 교체합니다.
3. USB 케이블을 한 번 뺐다가 다시 연결합니다.
4. `NetMD로 연결`을 누릅니다.

모드 오류 안내가 잠깐 나타나더라도 디스크를 지우지 말고 창을 닫은 뒤 NetMD 연결을
다시 시도하세요.

## 같은 미디어 형식을 되돌릴 때만 초기화

- 일반 MD 자체를 Hi-MD 형식으로 바꿀 때만 Hi-MD 포맷을 사용합니다.
- Hi-MD로 포맷한 일반 MD를 NetMD 형식으로 되돌릴 때만 NetMD 초기화를 사용합니다.
- 1GB Hi-MD 전용 미디어는 NetMD 형식으로 바꿀 수 없습니다.

## 음악 파일과 A3+

FLAC과 WAV 파일은 앱에서 변환하여 전송할 수 있고 Hi-MD PCM도 지원합니다.
`A3+`는 ATRAC3plus입니다. 버튼이 비활성화돼 있으면 설정의 `Encoding`에서
`LP / HiMD encoder to use`를 `Remote ATRAC Encoder`로 바꾸고 저장 후 재실행합니다.
원격 인코더는 인터넷 연결이 필요하며 파일을 변환 서버로 전송합니다.

## 연결이 안 될 때

1. 앱을 완전히 종료합니다.
2. 기기 전원과 배터리를 확인합니다.
3. USB 허브 대신 Mac 본체 포트와 다른 케이블을 사용해 봅니다.
4. USB를 다시 연결하고 앱을 실행합니다.
5. 기기 전원이 완전히 꺼졌다면 기존 Hi-MD 미디어를 넣기 전에 RAM 패치만 다시 적용합니다.

메인 화면 아래의 `진단 정보 복사` 버튼을 누르면 채팅으로 전달하기 쉬운 길이의 정보가
클립보드에 복사됩니다. 기기 모델, macOS 버전, 미디어 종류와 오류 직전 작업도 함께
알려주세요.
