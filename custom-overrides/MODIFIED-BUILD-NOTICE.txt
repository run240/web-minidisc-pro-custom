Web MiniDisc Pro 1.5.4 - Windows Custom Build
================================================

이 배포본은 ElectronWMD / Web MiniDisc Pro를 기반으로 수정한
비공식 Windows 커스텀 빌드입니다. 원본 프로젝트와 공식 배포본이 아닙니다.

Original projects
-----------------
ElectronWMD: https://github.com/asivery/ElectronWMD
Web MiniDisc Pro: https://github.com/asivery/webminidisc

---------------------------------

Main modifications
------------------
- Windows용 WinUSB 설치 및 MiniDisc 기기/모드 진단 보조 기능
- WinUSB 설치 진행 상태, 경과 시간, 결과 검증 및 응답 시간 초과 안내
- 여러 NetMD 및 Hi-MD 기기와 모드 전환을 위한 연결 화면
- 여러 MiniDisc 연결 시 모델과 USB 위치를 표시하는 기기 선택 화면
- NetMD/Hi-MD 포맷 흐름과 재실행 처리
- 한국어 UI 및 파일명 로마자 변환 보조
- Windows 커스텀 다크 테마, 아이콘, 로딩 화면, 팝업 UI
- Hi-MD 임시 편집, 일괄 적용 및 편집 안전장치
- NetMD 트랙 제목·순서 임시 편집, 일괄 적용 및 적용 결과 검증
- MD 전송 정지 감지, 추정 원인 안내 및 진단 정보 복사
- 기타 사용성 및 안정성 보완

Application icon artwork
------------------------
대표 애플리케이션 아이콘은 MiniDisc와 SonicStage 시대 네트워크 플레이어
관리 기능을 함께 나타내도록 이 커스텀 빌드를 위해 새로 제작했습니다.
Sony, MiniDisc, Walkman의 글자·로고와 기존 ElectronWMD의 DeviantArt
아이콘은 사용하지 않습니다.
